# Visual QA

Use a prepared Dev copy, default resource pack first; record language, resolution, GUI scale and graphics settings. [B] unreadable controls/missing assets/wrong state block release; [Q] record cosmetic severity for review, never silently pass.

- [ ] [B] All eight cultivars: cutting/grape/vine stages, harvested/regrowth states and labels match, no missing textures.
- [ ] [B] Trellis wood variants and attachment/growth states render correctly; inspect from all sides and at joins.
- [ ] [B] Netted/unnetted vines and water-channel irrigation controls remain legible; do not expect a nonexistent irrigation-device model.
- [ ] [B] Presses, fermentation/ageing barrels and cooperage/cask variants show correct states and interactions.
- [ ] [B] Winemaker/Cooper appearance and trade UI match actual profession, including isolated station and generated-village samples.
- [ ] [B] Red/white/aged bottles, placed bottles and partial fill/serving states agree with contents; inspect hand and placed forms.
- [ ] [B] Tasting Service, racks/crates/stands/shelves/cabinets/Archive display contents and labels correctly.
- [ ] [B] Desk at GUI scales 2, 3 and Auto (record unsupported sizes); long estate/plot names, many ledger/plot rows scroll without hidden controls or overflow.
- [ ] [B] Atlas map insert/select/pan/zoom/overlays: map edges/scales and owner plot bounds align; controls remain usable at tested scales.
- [ ] [B] English and each available shipped translation: labels resolve, no raw translation keys or clipped critical text. Record languages actually checked.
- [ ] [B] No purple/black missing models/textures across fixture board, inventory and UI.
- [ ] [Q] Check Z-fighting, phantom faces, lighting/occlusion, transparent joins and cellar darkness from multiple angles; capture defects with coordinates/settings.
