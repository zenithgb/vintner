## Corrected behavior

- Ordinary red, ordinary white, aged red and aged white bottles now share the
  traditional dark olive/green body. Red wine retains burgundy label and neck
  accents; white wine retains straw-gold/light label and neck accents; aged
  bottles add the existing restrained gold seal/border without losing their
  red/white identity.
- The same canonical four bottle presentations are used by placed bottles,
  storage displays, Tasting Services, Wine Baskets and inventory/held models.
  Partial-fill states, facing-aware storage slots, metadata and furniture
  variants remain unchanged.
- Creative Pick Block on an individually placed bottle now asks the server for
  a read-only copy of the actual stored wine. The server rechecks Creative
  mode, reach, block identity and current block-entity contents. Exact item
  components, custom name and remaining servings are copied; the source is not
  refilled, removed or mutated.
- Inventory matching remains component-exact, so a same-item bottle with
  different metadata cannot substitute for the targeted wine. Empty bottles
  and Survival requests are rejected by this Creative-copy path.
- Existing Tasting Service bottle targeting uses the same established payload
  and remains server-authoritative. Tray/service picking and per-slot storage
  targeting were not broadened or replaced.

## Model source and inspection

Bottle geometry was not redesigned. The repository has no bottle `.bbmodel` in
its current history; its established deterministic generator scripts remain the
authoritative source for the bottle model families. Palette changes were made
there and regenerated, avoiding a second hand-edited JSON source of truth.

The following canonical outputs were opened side by side in Blockbench:

- `src/main/resources/assets/vintner/models/block/wine_bottle_red_fill_4.json`
- `src/main/resources/assets/vintner/models/block/wine_bottle_white_fill_4.json`
- `src/main/resources/assets/vintner/models/block/wine_bottle_aged_red_fill_4.json`
- `src/main/resources/assets/vintner/models/block/wine_bottle_aged_white_fill_4.json`

Blockbench confirmed unchanged geometry. Its editor cannot resolve the
Minecraft/Vintner parent-texture namespace for these generated child models, so
palette correctness is enforced by the release-asset audit and still requires
the requested in-game visual approval at inventory and world scale.
