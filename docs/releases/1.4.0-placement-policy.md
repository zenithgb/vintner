# Vintner 1.4.0 village placement policy

This change gates each supported village start with a stateless, culture-salted
one-in-five decision from the world seed and village start chunk. An eligible
village then searches its bounded street candidates. A winery is added only
after its complete placement passes; Savanna and Taiga still commit the
building and field together. No global generation counter is used.

## Terrain and water

The final Taiga winery piece retains the established placement origin. Moving
the piece down alone moved nearby generated terrain down with it because the
rigid pool piece participates in Minecraft's terrain adaptation. Its
`groundLevelDelta` is now 2, which changes the terrain adaptation reference
without moving the authored building or its cellar. The Taiga field retains
its existing placement height and a separate support check.

The bounded candidate search requires equal world-surface and ocean-floor
heightmap values at each authored ground column. All Y=0 columns of both
paired templates are functional ground, so this rejects a winery or vineyard
on water while allowing water immediately outside the property. A field also
requires solid, non-fluid ground below each footprint column. The same dry
candidate check protects the three combined wineries.

## Engineering sample

The 500-start synthetic layout sample used the GameTest world's seed. The
numbers are eligible, successful, failed eligible, and duplicate/half pairs:

| Culture | Eligible | Successful | Failed eligible | Duplicate / half pair |
| --- | ---: | ---: | ---: | ---: |
| Plains | 101 | 95 | 6 | 0 / 0 |
| Desert | 83 | 78 | 5 | 0 / 0 |
| Savanna | 104 | 104 | 0 | 0 / 0 |
| Snowy | 111 | 109 | 2 | 0 / 0 |
| Taiga | 94 | 92 | 2 | 0 / 0 |

In a separate seed-1400 natural world, 25 villages per culture were generated
and their winery chunks physically loaded. Eligibility / complete winery
features were Plains 5 / 4, Desert 5 / 4, Savanna 6 / 5, Snowy 2 / 2, and
Taiga 3 / 3. No duplicate or half pair appeared. Vineyard-soil support was
complete in the sampled paired fields. These natural results are engineering
samples, not a visual or gameplay acceptance decision.
