# Phase 7E — Estate Reputation

Estate reputation is earned from actions and structures that already exist in
the world. It cannot be purchased, renamed into existence, or farmed by taking
multiple bottles from the same batch.

## Current reputation sources

- founding an estate provides the five-point starting score;
- registering named plots provides up to 24 points;
- planting vines and harvesting grapes each provide up to 20 points;
- distinct bottled batches provide up to 30 points;
- distinct archived vintages provide up to 40 points;
- the best verified bottle quality provides up to 35 points;
- each completed physical Phase 7D facility provides 10 points.

Batch identities are de-duplicated and bounded. Existing estate-ledger entries
are imported when the estate profile is reviewed, so estates created before
this phase do not have to start again.

## Ranks

| Rank | Required score |
| --- | ---: |
| New Estate | 0 |
| Established | 25 |
| Respected | 60 |
| Renowned | 110 |
| Celebrated | 170 |

Sneak-use the Vintner's Almanac in the air to review the current rank and the
next threshold alongside the estate profile and nearby facility survey.

## Manual acceptance

1. Found an estate and register a named plot.
2. Sneak-use the Almanac in the air. The profile should show `New Estate` and
   a score below the first 25-point threshold.
3. Plant and harvest a vineyard, then bottle a batch. The score should rise.
4. Take several bottles from the same batch. Its batch contribution should be
   counted only once.
5. Archive the batch and review the profile again. The score should rise for
   the newly archived vintage.
6. Build the four Phase 7D facilities and survey them. Each newly recognized
   facility should contribute 10 persistent points.
7. Remove a facility and survey again. The facility is no longer `Ready`, but
   the estate retains the reputation already earned for building it.

## Deliberately deferred

Contracts, festivals, trade reach, tasting events, awards, and merchant
benefits belong to later roadmap systems. Phase 7E does not fabricate those
events or expose unfinished market mechanics.
