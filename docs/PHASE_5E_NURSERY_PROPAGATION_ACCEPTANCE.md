# Phase 5E — Nursery Propagation Acceptance

The nursery bed makes successful grape genetics renewable without requiring a
full mature vineyard for every cutting. It is a visible, reusable propagation
loop rather than an abstract crafting recipe.

## Manual acceptance

1. Craft a Nursery Bed from oak planks around prepared Vineyard Soil.
2. Place it with open sky or adequate artificial light. The bed should sit five
   model units high and show soil inside a wooden frame.
3. Use one red or white grape cutting on the empty bed. The cutting should be
   consumed in Survival and the matching young plant should appear.
4. Let the plant progress through four visible rooting stages. Growth requires
   light level nine or higher.
5. Use an empty hand on the mature plant. It should yield three cuttings of the
   original colour and reset the same bed for another cycle.
6. A planted but immature bed should not yield cuttings, and a second cutting
   should not overwrite one already growing.
7. Breaking an occupied bed should return the reusable bed and the one inserted
   cutting. Only a normal mature harvest should multiply it to three.

Expanded grape varieties can use this same state-driven system later without
requiring a separate nursery block for every variety.
