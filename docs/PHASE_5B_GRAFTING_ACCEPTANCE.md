# Phase 5B — Grafting Acceptance

The grafting knife lets a player change the variety growing on an established
two-block vine without discarding its persistent root age.

## Manual acceptance

1. Craft a grafting knife with one iron ingot above one stick.
2. Hold the knife in the main hand and a cutting of the opposite colour in the
   off hand.
3. Use the knife on either half of a fully trained, two-block grapevine.
4. Both vine blocks should change variety, keep their original trellis wood,
   and return to fruit set so the new canopy must ripen once.
5. One cutting and one point of knife durability should be consumed in
   Survival. Neither is consumed in Creative.
6. Inspect before and after with the Almanac. The persistent vine age must not
   reset when the graft changes variety.
7. A matching cutting, an incomplete vine, or a non-vine block must not perform
   a graft or consume resources.

The current red/white cuttings exercise the system. Expanded Phase 5 varieties
can reuse the same grafting path without introducing separate root blocks.
