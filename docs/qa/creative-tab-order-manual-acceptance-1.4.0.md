# Vintner 1.4.0 Creative-tab order manual acceptance

Automated checks cover membership, exact stack uniqueness, semantic group
contiguity, wood-family order, cultivar order and Creative Search membership.
They do not establish the visual scanning experience. Complete this checklist
in a client at normal GUI scale before accepting the Creative-tab order.

- [ ] Grapes & Propagation reads as one coherent group.
- [ ] Vineyard content is contiguous.
- [ ] Pressing & Fermentation is contiguous.
- [ ] Ageing & Cooperage is contiguous.
- [ ] Cellar Storage is contiguous.
- [ ] Serving & Table is contiguous.
- [ ] Estate & Surveying is contiguous.
- [ ] No item looks obviously misplaced.
- [ ] Wood variants always use the same sequence.
- [ ] Cultivars always use the same sequence.
- [ ] No duplicate items appear.
- [ ] No expected item is missing.
- [ ] Creative Search still finds Vintner content.
- [ ] The tab remains practical at normal GUI scale.
- [ ] Large wood-variant groups do not make neighboring groups visually ambiguous.

Notes:

- Toasted Aging Barrel, Seasoned Aging Barrel and Cellar Cask intentionally do
  not appear as standalone Creative entries. They remain upgrade results from
  an ordinary Aging Barrel.
- Record GUI scale, observations and screenshots here during the manual pass.
